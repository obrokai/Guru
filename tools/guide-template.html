Guru 後台操作指南

主題版本 v1.2.6日期 2026-09-22登入 與現在相同的 /wp-admin/，帳號密碼不變

兩件事：上架一個作品（Showcase），以及調整網站字體大小。截圖是實際的後台畫面，紅框是要點的地方。最後附上其他常改項目的位置。

一、上架一個作品（Showcase）

事前準備

檔案規格
封面圖JPG，長邊 2000px 以內，檔案 2 MB 以內。設計原檔請先縮圖再上傳
封面比例任何比例都可以上傳，Work 頁卡片一律 4:3，網站會自動填滿、取正中央裁切。不想被裁掉內容就直接做成 4:3（例如 1600 × 1200 px），主體放畫面中間
影片（影片作品才需要）MP4，30 MB 以內，1080p 以下
為什麼要縮圖：主機處理大檔案的速度有限。太大的圖片會上傳失敗 —— 畫面左下角出現黑色錯誤訊息，檔案沒有存進去。先縮圖是最有效的解法。
1

Showcase → Add new showcase item

左側選單 Showcase，按上方的 Add new showcase item。

2

填寫編輯畫面

整個畫面長這樣。A 是必填欄位，B 是封面圖與分類，最後按右上角 發佈。中間的內文編輯器是選用的。

A  Showcase details — 標題正下方

欄位填什麼
Homepage position填 1～4，作品會出現在首頁「Our Work」四格（1 是大卡）。一個數字只有一個作品：原本佔這個數字的作品會自動讓位。留空 = 只出現在 Work 頁
Client name客戶名稱，顯示在專案名稱下方
Card labels卡片上的小標籤，逗號分隔，例如 Influencer Marketing, Social Media。留空 = 顯示作品的分類名稱
Video (optional)影片作品才填：按 Choose video → 上傳或從媒體庫選 MP4。有影片的卡片會自動播放

B  右欄 — 發佈、分類、順序、封面圖

Showcase categories：勾選分類（Campaign & PR／China Digital／Go-Global／Influencer／Social Media／Video）。Work 頁的篩選按鈕靠這個。

文章屬性 → 順序：數字小的排前面。

Cover image → Set cover image：封面圖一定要放在這裡，卡片顯示的就是這張。不要貼進中間的內文編輯器。

3

上傳封面圖

按 Set cover image 後會跳出視窗：① 上傳檔案 分頁 → ② 把圖拖進來或按 選取檔案 → 圖片出現在右側並打勾 → ③ 按右下角 Set cover image。

4

發佈

右上角 發佈。前台 Work 頁會出現新卡片；有填 Homepage position 的話，首頁「Our Work」也會更新。

常見狀況

狀況怎麼做
上傳一直轉圈，或左下角出現黑色錯誤訊息圖片太大。把長邊縮到 2000px、存成 JPG 再試。若還是失敗，把錯誤訊息整句抄下來給我們
修改已上架的作品Showcase → 點該作品 → 改完按 更新
暫時下架右欄「狀態」改成 草稿 → 更新（隨時可再發佈）
換首頁四格把新作品的 Homepage position 填成想要的數字 → 更新。原本佔那格的作品會自動讓位（畫面上方會提示是哪一個），不用再去改它

二、調整網站字體大小

1

外觀 → 自訂

進入即時預覽畫面。

2

Guru site settings → Typography

左側點 Guru site settings→Typography。四個欄位輸入 70～150 的數字（預設 100 = 原設計），右側預覽會即時更新；滿意後按最上方 發佈。想恢復原設計，改回 100 再發佈。

欄位影響範圍
Body text內文：段落、說明文字、卡片上的細節、頁尾連結
Section headings區塊標題：「Our Solutions」「Our Work」、卡片標題、首頁大數字、頁尾大標題
Page titles各頁最上方的大標題（About、Solutions、Work、Blog、Investor）
Navigation links導覽列的文字連結（兩顆按鈕不變）
建議一次調 5～10%（例如 100 → 110），電腦與手機一起看。標籤、按鈕、表單欄位不會跟著縮放，所以不會把版面撐壞。
