一、上架一個作品（Showcase）

事前準備

檔案規格
封面圖JPG，長邊 2000px 以內，檔案 2 MB 以內。設計原檔請先縮圖再上傳
影片（影片作品才需要）MP4，30 MB 以內，1080p 以下
為什麼要縮圖：主機處理大檔案的速度有限。太大的圖片會上傳失敗 —— 畫面左下角出現黑色錯誤訊息，檔案沒有存進去。先縮圖是最有效的解法。

編輯畫面長這樣

Showcase 的編輯畫面。綠色框是上架一定要填的；藍色框是選用。

標題：專案名稱，例如 Pandora × Influencers
AShowcase detailsHomepage position · Card labels · Client name · Video (optional)
C內文編輯器（選用）專案說明，只出現在作品自己的頁面。不要把封面圖貼在這裡。
發佈
狀態 · 頁面屬性 → 順序
BCover imageSet cover image → 選圖。卡片顯示的就是這張
BShowcase categories勾分類，Work 頁的篩選靠這個

步驟

  1. 左側選單 Showcase→Add new。

  2. 最上面輸入標題（專案名稱）。

  3. 標題正下方的 Showcase details（圖中 A），填四個欄位：

    欄位填什麼
    Homepage position填 1～4，作品會出現在首頁「Our Work」四格（1 是大卡）。留空 = 只出現在 Work 頁
    Card labels卡片上的小標籤，逗號分隔，例如 Influencer Marketing, Campaign / PR。留空 = 顯示作品的分類名稱
    Client name客戶名稱，顯示在專案名稱下方
    Video (optional)影片作品才填：按 Choose video → 上傳或從媒體庫選 MP4。有影片的卡片會自動播放

  4. 右欄 Cover image（圖中 B）→ Set cover image → 上傳或從媒體庫選圖 → 按右下角的藍色按鈕確認。

    封面圖一定要放在這裡，不要貼進中間的內文編輯器 —— 卡片只認 Cover image。

  5. 右欄 Showcase categories 勾選分類（China Digital／Influencer／Social Media／Video／Campaign & PR／Go-Global）。

  6. （選用）中間的內文編輯器（圖中 C）可以寫專案說明，只會出現在作品自己的頁面，卡片上不會顯示。

  7. 右上角 發佈。

發布後檢查

前台 Work 頁出現新卡片 —— 點卡片，有影片的會彈出播放視窗，沒影片的會開作品頁。有填 Homepage position 的話，首頁「Our Work」也會一起更新。

常見狀況

狀況怎麼做
上傳一直轉圈，或左下角出現黑色錯誤訊息圖片太大。把長邊縮到 2000px、存成 JPG 再試。若還是失敗，把錯誤訊息整句抄下來給我們
修改已上架的作品Showcase → 點該作品 → 改完按 更新
暫時下架右欄「狀態」改成 草稿 → 更新（隨時可再發佈）
調整 Work 頁的排列順序右欄「頁面屬性 → 順序」，數字小的排前面
換首頁四格把新作品的 Homepage position 填成想要的數字；原本佔那一格的作品改成留空

二、調整網站字體大小

  1. 外觀→自訂，進入即時預覽畫面。

  2. 左側 Guru site settings→Typography。

  3. 四個欄位，輸入 70～150 的數字（預設 100 = 原設計）：

    欄位影響範圍
    Body text內文：段落、說明文字、卡片上的細節、頁尾連結
    Section headings區塊標題：「Our Solutions」「Our Work」、卡片標題、首頁大數字、頁尾大標題
    Page titles各頁最上方的大標題（About、Solutions、Work、Blog、Investor）
    Navigation links導覽列的文字連結（兩顆按鈕不變）

  4. 改完數字，右側預覽會重新載入，直接看效果。

  5. 滿意後按最上方 發佈。想恢復原設計，把數字改回 100 再發佈即可。

建議一次調 5～10%（例如 100 → 110），電腦與手機一起看。標籤、按鈕、表單欄位不會跟著縮放，所以不會把版面撐壞。
